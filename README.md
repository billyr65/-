# 畢業生流向調查－專題成果展示

四頁式 GitHub Pages 靜態網站。

- `index.html`：首頁、專題團隊與摘要
- `research.html`：資料介紹、研究方法與動機
- `results.html`：滿一年、三年、五年分析區塊（需補真實數據）
- `conclusion.html`：結論（實際研究發現待補）
- `style.css`：四頁共用的外觀樣式
- `script.js`：手機版選單功能

請把以上檔案放在 GitHub 儲存庫根目錄；在 Settings → Pages 以 main / (root) 發布。
若需要背景照片，可另上傳 `images/graduation-bg.jpg`，不提供照片時仍有藍色背景。
專題團隊姓名、學年度、統計數字均請改為真實資料。
頁尾保留 HTML5 UP 模板設計來源標示；若沿用模板資產，亦請保留原有授權檔。
