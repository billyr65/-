
# 畢業生就業流向調查與趨勢分析

靜宜大學資料科學暨大數據分析與應用學系畢業專題成果展示網站。本專題以 **114 學年度畢業滿一年、滿三年及滿五年** 的畢業生就業流向調查為基礎，進行問卷資料整理、統計分析與資料視覺化，協助讀者了解畢業生的工作情形、薪資分布及在學期間學習經驗等調查結果。

網站結合 **R Markdown 統計報表**與 **R Shiny 互動式分析網站**，以不同方式呈現研究成果。

## 研究目的與內容

本專題將不同調查階段的問卷資料轉換為便於整理與分析的格式，經過資料清理、有效樣本核對與描述性統計後，探討目前工作狀況、職業類型、平均月收入、未就業原因、學習經驗及學校應加強的能力等主題。各階段題目與選項可能不同，因此依實際問卷內容分別分析，不預設可以直接比較所有題項。

研究與成果製作流程：

1. **資料轉換與整理：** 使用 R 整理欄位、編碼及選項格式。
2. **資料清理與核對：** 檢查有效樣本、缺漏值，以及單選題與複選題的處理方式。
3. **統計分析：** 彙整題目回答分布及主要分析指標。
4. **圖表與報表製作：** 使用 R Markdown 整合統計圖表、資料表與文字說明。
5. **互動式網站建置：** 使用 R Shiny 提供資料瀏覽、自訂比較分析與詳細資料查詢。

## 本機預覽與 GitHub Pages 部署

本網站是靜態 HTML 網站，下載或複製儲存庫後，可以開啟 `index.html` 進行基本預覽。若要透過 GitHub Pages 發布：

1. 將 HTML、`style.css`、`script.js` 及 `images` 資料夾放在儲存庫根目錄。
2. 在 GitHub 儲存庫的 **Settings → Pages** 選擇發布來源（例如 **Deploy from a branch**、`main`、`/(root)`；依儲存庫設定而定）。
3. 確認 **Actions** 裡的 Pages 部署成功，再由 **Settings → Pages** 開啟網站。
4. 如果圖片未顯示，確認 HTML 的圖片路徑、檔名及大小寫與 GitHub 上完全一致。

## 資料使用與注意事項

- 原始問卷資料可能包含個人識別資訊；公開網站僅應提供經確認可公開的彙整統計與問卷題項，不應上傳含有姓名、學號、聯絡方式等資訊的原始檔案。
- 不同學年度、調查階段及題目可能有不同的有效樣本數；實際統計數字請以已核對的分析結果為準。
- 本網站展示研究流程與成果，未來的跨年度追蹤、前端資料匯入、雲端權限管理等功能屬於後續規劃，不代表已完成。
